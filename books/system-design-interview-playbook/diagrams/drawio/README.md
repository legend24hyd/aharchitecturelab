# Draw.io sources

Editable diagrams.net files (`.drawio`) live next to a publishable SVG (`.drawio.svg`).

Open `.drawio` in [diagrams.net](https://app.diagrams.net) or the VS Code Draw.io extension. After visual edits, export SVG over the `.drawio.svg` file so Kindle/EPUB keep a sharp image.

Do not commit huge PNG screenshots of the same diagram unless a store rejects SVG (rare).
