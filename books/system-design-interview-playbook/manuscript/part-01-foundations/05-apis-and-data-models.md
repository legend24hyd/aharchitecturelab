# APIs and data models

*Outline for Version 1.0 — expand during writing.*

## Start with the verbs

REST, RPC, events. Choose one primary style and say why. Sketch 4–6 operations, not forty.

## Entities and keys

What is the unit of consistency? What is the lookup key on the hot path?

## Pagination, idempotency, errors

Interviews go well when you mention idempotency keys before the interviewer has to drag them out of you.

## Events vs request/response

If a user should not wait, it is an event. Draw it that way.
